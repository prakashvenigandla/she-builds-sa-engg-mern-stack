### Classroom Activities 
#### Activity 1: Component Creation Workshop Students design and develop reusable UI components such as:

● Navigation Bar 
● Cards 
● Forms 
● Modal Windows 
● Dashboard Widgets 
Outcome: Understanding component-based architecture and reusability. 
#### Activity 2: Dynamic Data Rendering Lab 
Students consume data from APIs and dynamically display: 
● Student Lists 
● Product Catalogs 
● News Feeds 
● Weather Information 
Outcome: Understanding data-driven UI development. 
#### Activity 3: State Management Challenge 
Students create interactive applications involving: 
● Counters 
● Task Managers 
● Expense Trackers 
● Shopping Carts 
Outcome: Understanding React state management and application flow. 
#### Activity 4: Routing & Navigation Exercise 
Students implement: 
● Multi-page navigation 
● Dynamic routes 
● Protected pages 
● Navigation menus 
Outcome: Understanding SPA navigation patterns. 
#### Activity 5: Team UI Development Sprint 
Students work in teams to develop a dashboard interface using reusable React components.

Outcome: Exposure to collaborative frontend development practices.
